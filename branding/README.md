# BOX DEFENSE — launch branding

The branding should stay as basic as the game.

## Identity

**Name:** BOX DEFENSE

**Core mark:** one plain square.

**Tone:** dry, literal, monotonous on purpose.

**Tagline:**

> YOU DECIDE WHAT WE ADD NEXT.

## Visual rule

Do not make the branding more elaborate than the game.

Use:

- very dark background;
- white/light-gray boxes;
- plain bold sans-serif text;
- minimal motion/editing;
- no mascot until the community gives the box one.

The game icon source is at `assets/branding/icon.svg`.

The YouTube banner source is at `branding/youtube-banner.svg`.

## YouTube channel

Suggested channel name:

```text
BOX DEFENSE
```

Suggested description:

```text
I made Box Defense.
Players vote on what I add next.
```

## Short #001

Target length: about five seconds.

```text
[Gameplay: boxes moving toward the center]

"I made a game."

[center box shoots]

"It's Box Defense."

CUT.
```

No intro animation, no exaggerated thumbnail language, no fake reaction.

## Short #002

```text
[Community Vote screen]

"I don't know what to add."

[show two choices]

"So you decide."

CUT.
```

## Recurring update format

```text
"You voted for ______."

[show the feature]

"I added ______."

CUT.
```

The joke is that the game becomes increasingly absurd while the presentation stays exactly as dry as it was on day one.
